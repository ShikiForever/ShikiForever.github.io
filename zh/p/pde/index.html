Lax-Milgram theorem

$$ \begin{cases} Lu=f & \text{in } D\\ \mathrm{BC} & \text{on } \partial D, \end{cases} $$

where $D$ is an open, connected, bounded subset of $\mathbb{R}^n$.

$$ Lw=\underbrace{-\sum_{i,j=1}^{n}D_i(a_{ij}D_jw)}_{\text{principal part of }L}+\sum_{i=1}^{n}b_iD_iw+d_0w. $$

For a non-homogeneous Dirichlet problem, we can use an auxiliary function to transform it into a homogeneous problem. However, the existence of such an auxiliary function will be given in Chapter 4 by the surjectivity of the Trace operator.

Definition 2.1: A (real) matrix $A$ is said to be positive definite if $Av\cdot v>0$ for every $v\neq 0,v\in \mathbb{R}^n$.

Exercise 2.1： A matrix $A$ is positive definite iff it’s coercive.

Proof. $v^TAv=v^T\frac{A+A^T}{2}v=:v^TBv\geq \lambda_{\min}v^Tv$. So $A$ is positive definite iff $B$ is positive definite iff $\lambda_{\min}>0$ iff $B$ is coercive.

Definition 2.1 (Positive definite matrix). A real matrix $A\in\mathbb{R}^{n\times n}$ is said to be positive definite if

$$ v^TAv>0,\qquad \forall\,v\in\mathbb{R}^n\setminus\{0\}. $$

Exercise 2.1. A matrix $A$ is positive definite if and only if it is coercive.

Proof. Let $B=\frac{A+A^T}{2}$ be the symmetric part of $A$. Then

$$ \begin{align*} v^TAv &=v^TBv\\ &\geq \lambda_{\min}(B)\|v\|^2. \end{align*} $$

Since $B$ is symmetric, we have

$$ \begin{align*} A\text{ is positive definite} &\iff B\text{ is positive definite}\\ &\iff \lambda_{\min}(B)>0\\ &\iff A\text{ is coercive}. \end{align*} $$

$\square$

Exercise 2.2. Consider a positive definite matrix $A$ (thus satisfying $Av\cdot v\geq \alpha |v|^2$ for every $v\in\mathbb{R}^n$, for a suitable $\alpha>0$). Then the real part of an eigenvalue of $A$ is greater than or equal to $\alpha$; in particular, a positive definite matrix is non-singular.

Assume that $\lambda$ is a eigenvalue of $A$, so there is a $v\in\mathbb{C}^n$.

s.t. $Av=\lambda v$

So

$$ \bar{v}^TAv=\lambda\bar{v}^Tv=\lambda|v|^2. $$$$ \begin{align*} \bar{v}^TAv &=(v_0-iw_0)^TA(v_0+iw_0)\\ &=v_0^TAv_0+w_0^TAw_0+i(v_0^TAw_0-w_0^TAv_0). \end{align*} $$$$ \Rightarrow \lambda=\frac{\bar{v}^TAv}{|v|^2} $$$$ \begin{align*} \Rightarrow \operatorname{Re}\lambda &=\frac{\operatorname{Re}\bar{v}^TAv}{|v|^2}\\ &=\frac{v_0^TAv_0+w_0^TAw_0}{|v|^2}\\ &\geq\frac{\alpha(|v_0|^2+|w_0|^2)}{|v|^2}\\ &=\alpha. \end{align*} $$

Exercise 2.3.

(i) A matrix $A$ is positive definite if and only if $\dfrac{A+A^T}{2}$ is positive definite.

(ii) A matrix $A$ is positive definite if and only if all the eigenvalues $\lambda_i$ of $\dfrac{A+A^T}{2}$ are strictly positive.

Definition 2.2 The partial differential operator $L$ is said to be (uniformly) elliptic in $D$ if the matrix $\{a_{ij}(x)\}_{i,j=1}^n$ is (uniformly) positive definite, i.e., if there exists a constant $\alpha_0>0$ such that

$$ \sum_{i,j=1}^n a_{ij}(x)\eta_j\eta_i\geq\alpha_0|\eta|^2 $$

for a.e. $x\in D$, for every $\eta\in\mathbb{R}^n$.

Riesz representation THM & Lax-Milgram THM

from finite dimensional linear system to infinite dimensional PDE

We know that linear system ($Q \in \mathbb{R}^{m \times m}$)

$$Qq = p$$

has a unique solution iff $\forall r \in \mathbb{R}^{m}$

$$(Qq, r) = (p, r)$$

Notice that LHS is a bilinear form about $q$ & $r$, and RHS is a linear functional of $r$. i.e. we are considering

$$B(q, r) = F(r)$$

and from there, we know that in $\mathbb{R}^{m}$ a linear function can be written as a given inner product with a unique element. i.e. given $q \in \mathbb{R}^{m}$,

$$B(q, r) = (M(q), r)$$

and by uniqueness we know that $M$ is linear about $q$. Similarly,

$$F(r) = (g_{F}, r)$$

So the problem changes into

$$(Mq, r) = (g_{F}, r)$$

and again this problem has a solution iff $Mq = g_{F}$, iff $M$ is non-singular. and we know that positive definite is a suff condition.

Now back to infinite dimension. first we need an inner product. say for example we consider $L^{2}$ one.

for the problem

$$Lu = f \quad \text{in } D$$

we consider equation

$$ (Lu,v)=(f,v), $$

i.e.

$$ \begin{aligned} \int_D \left[ -\operatorname{div}(A\nabla u)\,v +(b\cdot\nabla u)v +cuv \right]\,dx &= \int_D fv dx. \end{aligned} $$

by div THM,

$$ \begin{aligned} \underbrace{ \int_D \left[ A\nabla u\cdot\nabla v +(b\cdot\nabla u)v +cuv \right]\,dx -\int_{\partial D} (A\nabla u\cdot n)v\,dS }_{B(u,v)} &= \underbrace{ \int_D fv\,dx }_{F(v)}. \end{aligned} $$

So this turns out to be the reason why we consider such a “weak” form. We only need $A, b, c$ to be $L^{\infty}$, $\nabla u, \nabla v, u, v, f$ to be $L^{2}$, then we can define the bilinear form and linear functional.

since $L^{2}$ is too big, we can consider a dense subspace as long as the bilinear form and the linear functional is continuous. for example, we know that $C_{c}^{\infty}(D)$ is dense in $L^{2}(D)$. So we only need to check that for $v \in C_{c}^{\infty}(D)$

$$B_{L}(u, v) = F(v)$$

And this time

$$B_{L}(u, v) = \int_{D} (A \nabla u) \cdot \nabla v + b \cdot \nabla u v + c u v$$

Now we turn to consider where we solve this eq. i.e. what is $V\ni u$?

(1) we need $\forall u \in V$, $u$ and $\nabla u$ to be $L^{2}$. so $V$ must be a subspace of $L^{2}$.

(2) we need $V$ to be a Hilbert space so that by Riesz Representation THM we can write $B_{L}$ and $F$ as an inner product with some element, and in some sense we can turn back to the original problem.

(3) we need $B_{L}$ and $F$ to be continuous so that we can use the denseness and Riesz representation THM. and it’s ez to prove that Continuity $\Leftrightarrow$ boundedness.

(4) $C_{c}^{\infty}(D)$ is dense in $V$. only for Dirichlet BC.

from the continuity of $B_{L}$ and $F$, we first notice that $L^{2}$ is not sufficient. consider

$$B(u, v) = \int_{D} \nabla u \cdot \nabla v$$

(First we notice that it’s an inner product of derivatives)

Let $D = (0, \pi)$ and $u_{n} = v_{n} = \sin(nx) \in L^{2}$

However,

$$\begin{align*} B(u_{n}, u_{n}) &= \int_{0}^{\pi} n^{2} \cos^{2}(nx) dx \\ &= \frac{\pi}{2} n^{2} \end{align*}$$$$\begin{align*} \|u_{n}\|_{L^{2}}^{2} &= \int_{0}^{\pi} \sin^{2}(nx) dx \\ &= \frac{\pi}{2} \end{align*}$$$$\frac{B(u_{n}, u_{n})}{\|u_{n}\|_{L^{2}}^{2}} = n^{2}$$

$B$ is not bounded under $L^{2}$-norm. So we need to consider an inner product which is associated with derivatives.

For example,

$$(w, v)_{1} = \int_{D} w \cdot v + \nabla w \cdot \nabla v$$

for the Dirichlet BC. Since we need to differentiate $u$ so we may consider

$$V = \{u \in C^{1}(\overline{D}) \mid u|_{\partial D} = 0\}$$

However, as we can see in Problem 2.8, $V$ is not Hilbert ambient space. So we need to enlarge $V$ and consider a new definition of derivatives.

Now assume that all problems have been solved and $V$ is a Hilbert space and we derive a sufficient condition to solve $Lw = f$.

THM 2.8 (Lax-Milgram THM) $B: V \times V \rightarrow \mathbb{R}$ a bilinear form. $F: V \rightarrow \mathbb{R}$ a linear functional. $B$ is bounded and coercive.

i.e.

$$|B(u, v)| \le \gamma \|u\| \|v\|$$

$$B(u, u) \ge \alpha \|u\|^{2}$$

$F$ is bounded.

$$|F(v)| \le M \|v\|$$

Then $\exists ! u \in V$ s.t.

$$B(u, v) = F(v)$$

and

$$\|u\| \le \frac{M}{\alpha}.$$

Notice that

$$(L u, v) = (f, v)$$

$$\alpha \|u\|^{2} \le |(L u, u)| = |(f, u)| \le M \|u\|$$

$$\|u\| \le \frac{M}{\alpha}$$

Proof:

$\forall w \in V$, $B(w, \cdot)$ is a linear functional. So $\exists ! A(w) \in V$, s.t.

$$B(w, \cdot) = (A(w), \cdot)$$

and

$$\begin{align*} B(\lambda_{1} w_{1} + \lambda_{2} w_{2}, \cdot) &= \lambda_{1} B(w_{1}, \cdot) + \lambda_{2} B(w_{2}, \cdot) \\ &= \lambda_{1} (A(w_{1}), \cdot) + \lambda_{2} (A(w_{2}), \cdot) \\ &= (\lambda_{1} A(w_{1}) + \lambda_{2} A(w_{2}), \cdot) \end{align*}$$

by uniqueness we know $A$ is linear. similarly

$$F(\cdot) = (g_{F}, \cdot)$$

Now we only need to find $u$ s.t.

$$Au = g_{F}$$

We only need $A$ to be bijective.

① Injective:

$$Av = 0 \Rightarrow (Av, v) = B(v, v) \ge \alpha \|v\|^{2} \Rightarrow v = 0$$

② Surjective:

  1. first we prove that $A$ is bounded.

    $$\|Ax\|^{2} = (Ax, Ax) = B(x, Ax) \le \gamma \|x\| \|Ax\|$$

    $$\Rightarrow \|Ax\| \le \gamma \|x\|$$

  2. then we prove that $R(A)$ is closed

i.e. $Ax_{n} \rightarrow y \Rightarrow y = Ax$ for some $x$. to find an $x$, we use completeness.

$$\begin{align*} \|x_{n} - x_{m}\|^{2} &\le \frac{1}{\alpha} B(x_{n} - x_{m}, x_{n} - x_{m}) \\ &= \frac{1}{\alpha} (Ax_{n} - Ax_{m}, x_{n} - x_{m}) \\ &\le \frac{1}{\alpha} \|Ax_{n} - Ax_{m}\| \|x_{n} - x_{m}\| \end{align*} $$

$$\Rightarrow \|x_{n} - x_{m}\| \le \frac{1}{\alpha} \|Ax_{n} - Ax_{m}\|$$

$\{Ax_{n}\}$ is Cauchy $\Rightarrow \{x_{n}\}$ is Cauchy $\Rightarrow \exists x \in V$ s.t. $x_{n} \rightarrow x$. $\Rightarrow Ax = y$.

Since

$$V = R(A) \oplus R(A)^{\perp}$$

So we only need to prove that $R(A)^{\perp} = 0$.

If $(Ax, y) = B(x, y) = 0, \forall x$, then particularly for $x=y$

$$(Ay, y) = B(y, y) = 0$$

$$\Rightarrow y = 0$$
