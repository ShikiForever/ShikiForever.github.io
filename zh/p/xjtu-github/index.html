一、直接提升校园生活效率

项目 能解决什么 值得借鉴的思路
XJTUToolBox Windows/macOS 桌面百宝箱：课表、成绩/GPA、考勤、空闲教室、一键评教、教务通知订阅，多账户支持 把分散的学校系统统一成一个本地客户端。它还把登录、教务、考勤、研究生系统、思源学堂等接口分成独立模块，非常适合二次开发
岱宗盒子 / xjtu-toolbox-android Android 校园工具箱：课表、考试、成绩、空教室、考勤、校园卡、图书馆座位、思源学堂、课程回放、体测、评教、通知、教材 目前功能覆盖最广。尤其值得参考“所有数据直接访问学校接口，不经过作者服务器”和“把校园功能包装成 AI 可调用工具”
XJTU-Annual-Eat 获取校园卡账单，生成年度食堂消费统计、图表和 Markdown 报告 可以扩展成“校园生活年报”：食堂偏好、月度开销、消费地点、早中晚餐规律
XJTU-SCORE 定期查询教务成绩，有新成绩时发邮件提醒 很适合扩展成成绩变动通知、补考提醒、学分进度预警
xjtu-grade 查询成绩并计算排名 也是其他项目参考的西交登录、教务访问实现之一
AverageScore 西交平均分计算器 小而实用，可继续增加不同学院的 GPA 规则、保研排名模拟
XJTU Course Genius 跨平台选课辅助客户端：课程分类浏览、已选课程、冲突课程、CAS/MFA 登录、自动查询余量 前后端分离的设计很完整，可以参考它做“选课规划器”“课程冲突可视化”“候选方案比较”。自动抢课部分要留意学校规则
XJTU_CERNET 校园网自动登录 虽然很老，但很适合作为路由器、开机任务、宿舍设备自动联网的原型
ip-xjtu 整理西交 IP 地址段 可用于判断校内外网络、自动切换 WebVPN、代理路由或校园服务可达性

其中，最值得直接研究代码的是 XJTUToolBox 和岱宗盒子。两者已经把大量校园系统的认证、Cookie、WebVPN、接口解析等重复工作做好了。

二、思源学堂、录播和课件处理

1. 思源学堂课件与回放下载助手

AstralArtisan/xjtu-lms-downloader

这是我检索到功能最完整的录播相关项目：

  • 批量下载 PDF、PPTX、DOCX、压缩包等课件；
  • 下载“老师路”和“电脑路”两路录像；
  • 同时覆盖思源学堂“录播教材”和 RMS“直录播”入口；
  • 能找到只出现在直录播中的调课回放；
  • 支持整页勾选、批量下载、进度、失败重试；
  • 可以把电脑路画面和老师路音频用 FFmpeg 重新组合。

它提供 Tampermonkey 脚本和浏览器扩展两个形态，非常适合参考“怎样给现有校园网页注入效率功能”。

注意：项目包含下载教师未开放下载的附件功能。即使技术上可行，也应遵守课程版权和学校规定，只处理自己有权访问的学习资料。

2. iSpace 研究生课程视频下载

KnownCircle/XJTU-Get_iSpace_videos

功能包括：

  • 浏览器登录/扫码登录；
  • 获取自己的课程列表；
  • 批量选择视频；
  • 自动按照课程名、日期、序号和“教室/电脑”视角命名；
  • 识别同一节课的多路录像。

README 中提到的限制是：课程列表本身暂时只处理第一页，但单门课程的视频列表支持分页。这种脚本很适合继续增加断点续传、自动分章和课件对齐。

3. 其他轻量下载器

  • XJTU-Slides-Fetcher：思源学堂课件下载脚本。
  • XJTU-CLASS-DOWNLOADER：下载西交在线学习平台视频。
  • xjtu-lms-courseware-downloader：批量下载思源学堂课程课件。

这些小项目代码量通常更少，反而适合快速看懂学校接口和认证流程。

4. 你提到的录播处理 Gist

zly2006/西安交通大学录播课.py

这个脚本的实际逻辑是：

  1. 从 class.xjtu.edu.cn 获取课程和视频；
  2. 下载录播；
  3. 用 FFmpeg 每五秒抽取一帧；
  4. 用 OpenCV 比较前后画面的灰度差；
  5. 只保留画面变化明显的关键帧。

因此它更接近“自动提取 PPT 翻页/课程关键画面”，而不只是简单的视频分集。可以进一步改成：

  • 通过画面变化自动生成章节；
  • OCR 识别 PPT 标题；
  • 生成带时间戳的目录；
  • 自动导出 Anki 卡片；
  • 将关键帧、字幕和录播时间轴对齐；
  • 点击笔记即可跳转到对应视频位置。

这可能是最符合你所说“思路启发”的项目。

五、适合拿来开发新工具的“基础设施”

如果你想自己维护、组合或者做新项目，下面两个尤其有价值：

  • Auth.xjtu：Python 的西交 OpenPlatform OAuth 自动认证库。
  • XJTUToolBox 中的独立接口模块：包含统一登录、WebVPN、教务、评教、成绩、考勤、研究生系统、空闲教室和思源学堂接口。

基于现有项目，我认为最值得继续做的几个新方向是：

  1. “录播智能笔记”：下载回放 → 语音转写 → PPT 关键帧 → 自动章节 → 可搜索笔记。
  2. “个人校园仪表盘”：课表、作业、考试、成绩、校园卡、图书馆座位统一时间线。
  3. “通知去重与摘要”：聚合教务处和学院网站，只推送与个人专业、年级相关的通知。
  4. “培养方案进度检查”：导入成绩单，自动判断已修学分、缺失课程和毕业风险。
  5. “空教室+图书馆座位推荐”：结合当前位置、下一节课地点和空闲时间推荐自习位置。
  6. “校园生活年报”：把食堂、图书馆、课表、运动、考试等数据做成完全本地生成的年度报告。

安全方面，凡是需要密码、Cookie、hallticket 或 API Key 的项目，最好自己审计并在本机运行，不要把凭据交给陌生网页服务；自动评教、抢课、打卡和下载未开放资源也需要先确认学校规则。
